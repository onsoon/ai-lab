이번 시간에 배울 것

  • 디지털 데이터와 아날로그 데이터의 특징을 이해하고, 인공지능에 활용할 수 있는 데이터의 유형이나 형태를 탐색할 수 있어요.
  • 인공지능이 만들어지는 과정을 체험하고, 인공지능이 사회에 미치는 영향을 탐색할 수 있어요.

      미션 2 · 생활 속 인공지능

      우리 곁의 인공지능 찾기

      인공지능이란 사람의 지능을 모방(다른 것을 본뜨거나 본받음)하여 대상의 이해, 새로운 내용의 학습, 사실 예측, 문제 해결 등의 작업을 수행하는 프로그램이에요. 우리 생활의 다양한 분야에서 쓰이고, 쓰이는 곳이 점점 넓어지고 있어요.

      인공지능 스피커

      “날씨에 어울리는 음악 틀어 줘.” 하고 말하면 날씨나 분위기에 맞는 음악을 골라서 들려줘요.

      인공지능 텔레비전

      내가 자주 보던 프로그램을 기억했다가 좋아할 만한 프로그램을 골라서 보여 줘요.

      인공지능 번역

      “시청으로 어떻게 가야 하나요?”를 외국어로 바꿔 줘서 외국인과 대화할 수 있어요.

      생활용품에 인공지능 더하기

      우리가 사용하는 생활용품에 인공지능을 적용한다면 어떻게 활용할 수 있을지 상상해서 적어 보세요. 다 적으면 예시 보기로 다른 생각도 살펴봐요.

      화분

      흙이 얼마나 말랐는지, 햇빛이 얼마나 드는지 데이터를 모아서 물을 줄 때가 되면 스스로 물을 주거나 알려 줘요.

      안경

      눈앞에 보이는 외국어 간판을 우리말로 번역해서 보여 주거나, 길을 찾을 때 가는 방향을 화살표로 알려 줘요.

      예) 물감으로 그린 그림, 아날로그 체중계로 측정한 몸무게, 노래를 부르는 목소리, 손 글씨로 쓴 편지

      디지털 데이터

      아날로그 데이터를 컴퓨터가 처리할 수 있는 디지털 기호 형식으로 변환한 것이에요.

      예) 스마트폰으로 촬영한 사진, 디지털 체중계로 측정한 몸무게, 온라인 생중계 영상의 소리, 누리 소통망의 글자·이미지

      함께 해 보기 · 데이터 형태 카드 놀이

      1. 3~4명이 한 모둠이 되어, 모든 카드를 뒷면이 보이도록 펼쳐 놓아요.
      2. 순서를 정하고 차례가 되면 카드를 두 장씩 뒤집어요.
      3. 두 장의 데이터가 같은 형태(아날로그끼리 또는 디지털끼리)이면 두 장을 가져가고, 다른 형태이면 다시 뒤집어 놓아요.
      4. 모든 카드를 가져가면 끝! 카드를 가장 많이 가진 사람이 이겨요.

      미션 4 · 인공지능과 데이터

      AI가 배우는 데이터의 종류

      사람이 지식과 경험을 통해 대상을 인식하고 결과를 예측하는 것처럼, 인공지능도 데이터를 학습하여 대상을 인식(구별하고 이해하는 과정)하고 결과를 예측해요. 데이터는 인공지능을 만드는 재료가 돼요. 인공지능에 활용할 수 있는 데이터 유형에는 글자, 숫자, 이미지, 소리 등이 있어요.

      스스로 해 보기 · 국어사전 앱으로 데이터 탐색하기

      국어사전 애플리케이션은 세 가지 방법으로 검색할 수 있어요. 각 방법이 어떤 데이터를 인식하는지 골라 보세요.

      교과서 QR로 연결되는 ‘퀵드로우’ 놀이처럼, 내가 그린 그림(이미지 데이터)을 인공지능이 알아맞히는 것도 같은 원리예요.

      미션 6 · 엔트리 실습 1 (스스로 해 보기)

      갈색 푸들과 몰티즈를 구별하는 AI

      강아지 이미지 데이터를 모아 품종을 분류하는 인공지능 모델을 만들고, 카메라로 강아지 사진을 보여 주면 품종을 말해 주는 프로그램을 만들어요. 한 단계를 끝낼 때마다 눌러서 체크하세요.

      엔트리 열기 (playentry.org)새 탭에서 열려요. 작품 만들기로 들어가세요.

      1. 데이터 수집과 레이블링 · 모델 생성과 평가

      1. 블록 꾸러미에서 인공지능을 누르고 인공지능 모델 학습하기를 선택해요.
      2. 분류: 이미지를 고르고 학습하기를 눌러요. 이미지, 텍스트, 소리를 분류하는 모델을 만들 수 있어요.
      3. 모델명에 강아지 분류 모델을 입력해요. 모델명은 한 번 정하면 바꿀 수 없으니 잘 정해요.
      4. 클래스 이름을 갈색 푸들, 몰티즈로 입력하고, 준비한 이미지를 각각 5장 이상 업로드해요. (+ 클래스 추가하기로 클래스를 늘릴 수 있어요.)
      5. 모델 학습하기를 눌러 모델을 만들어요. 학습이 100%가 될 때까지 기다려요.
      6. 결과 칸에 테스트 데이터(학습에 쓰지 않은 사진) 한 개를 넣어 바르게 분류하는지 확인해요.
      7. 오른쪽 위 적용하기를 눌러 만든 모델을 저장해요.

      2. 모델 활용 · 프로그램 만들기

      1. 카메라를 쓰기 위해 인공지능 블록 불러오기 → 비디오 감지 → 사물 인식을 선택하고 불러오기를 눌러요.
      2. 아래 블록과 똑같이 조립해요.
      3. ▶ 시작하기를 누르고, 갈색 푸들과 몰티즈 사진을 카메라에 보여 주며 바르게 말하는지 확인해요.

      미션 7 · 엔트리 실습 2 (함께 해 보기)

      신호등을 알아보는 자율 주행 자동차

      신호등의 색을 인식해 분류하는 인공지능 모델을 만들고, 신호등 색에 따라 자동차가 움직이거나 멈추는 프로그램을 만들어요. 먼저 아래 미리 보기로 완성된 모습을 확인해 보세요.

      미리 보기 · 카메라가 본 신호등 색

      신호등 색이 노랑일 때에는 멈추는 것이 더 안전해요. 그래서 노랑일 때도 0만큼 움직여요(멈춰요).

      1. 모델 생성 및 평가

      1. 엔트리 인공지능 블록 꾸러미에서 인공지능 모델 학습하기 → 새로 만들기 → 분류: 이미지 → 학습하기를 선택해요.
      2. 모델 이름에 신호등 색 분류 모델을 입력해요.
      3. + 클래스 추가하기로 세 개의 클래스를 만들고, 클래스명을 빨강 노랑 초록으로 입력한 뒤 이미지를 각각 5장 이상 업로드해요. (교과서 128쪽 활동지 3 ‘자율 주행 로봇 신호등’을 이용해도 좋아요.)
      4. 모델 학습하기를 눌러 모델을 만들고, 테스트 데이터를 넣어 분류 결과를 확인해요.
      5. 적용하기를 눌러 만든 모델을 저장해요. 이 모델은 120쪽에서 다시 사용해요.

      2. 모델 활용 · 오브젝트별 코드

      미션 8 · 인공지능과 사회

      인공지능이 바꾸는 우리 사회

      인공지능은 우리 사회의 여러 분야에서 다양한 방식으로 발전을 이끌고 있어요. 이런 발전은 편리함을 주지만, 때로는 새로운 노력과 도전을 요구하기도 해요. 카드를 눌러 인공지능이 어떻게 돕는지 확인해 보세요.

      직업은 어떻게 바뀔까?

      기존 직업이 자동화되거나, 인공지능과 협업하여 새로운 형태의 직업으로 바뀌기도 해요. 인공지능을 개발하고 관리하는 새로운 직업도 생기고 있어요. 직업 카드를 골라 알맞은 상자에 넣어 보세요.
